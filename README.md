# Agama — Brand Assets

Official Agama logo files. Everything is vector SVG with outlined text — no font
dependency, so the files render identically in browsers, Slack, Figma, Office and PDF.

**Not sure which one to take? Use [`agama-logo.svg`](agama-logo.svg).**

Names follow `agama-<form>-<variant>.svg`, where the form is one of:

- **lockup** — symbol next to the "Agama" wordmark
- **icon** — symbol inside a solid green container (app icons, avatars)
- **mark** — symbol on its own, transparent background

## Files

### Lockup — symbol + wordmark

| File | What it is | Size | Use it for |
|---|---|---|---|
| [`agama-logo.svg`](agama-logo.svg) | Green squircle icon + green wordmark | 500 × 112 | **The default logo.** Most-used file in the repo. |
| [`agama-lockup-green.svg`](agama-lockup-green.svg) | Flat green symbol + green wordmark | 500 × 112 | Light or beige backgrounds, where the squircle feels too heavy. |
| [`agama-lockup-black.svg`](agama-lockup-black.svg) | All black | 500 × 112 | Monochrome print, documents, partner one-pagers. |
| [`agama-lockup-beige.svg`](agama-lockup-beige.svg) | All beige | 500 × 112 | Dark and green backgrounds. |

## Usage

Keep clear space around the logo equal to at least the height of the symbol.
Don't recolor, stretch, rotate or add effects to the mark — pick the variant that
already matches your background instead.
